「Quicker社区版」 是一款只在 macOS 和部分 Linux 桌面上运行的「Quicker 风味」效率软件 ，由社区成员开发和提供支持。

「Windows Quicker」 是 「Quicker社区版」 的参考对象。「Quicker 社区版」 在一定程度上弥补了 Quicker 无法在其他平台直接运行的问题。

如果您是首次通过此了解到 “Quicker” 的，那么您应该先去看一下下面的链接，这是 Windows Quicker 的官网：

[Quicker软件 您的指尖工具箱 - Quicker](https://getquicker.net/)

如果您有 Windows PC，您可以下载体验一下。如果您从 “macOS/Linux 相关” 话题听闻到此，您也可以简单的了解一下。

## 常见问题

### 这是谁开发的软件？

原版 Quicker，或者说 Windows 版 Quicker， 是由 CL 开发的，仅提供 Windows 版本；社区成员 🌍地球 在闲暇时间从头开发了一个叫做 Quicker 社区版 的 Quicker 风味软件。 

### Quicker 社区版有多少功能？

Quicker 社区版的功能没有 Windows Quicker 功能多，Windows Quicker 有分 1.0 版本 和 2.0，社区版更像 1.0 版本。由于 Quicker 社区版的软件开发并非 🌍地球 全职开发，因此，若您遇到缺少的功能，您可以加入 [QQ群](https://getquicker.net/KC/Kb/Article/904) 找到 @🌍-学习 提一下，这样我就知道您的需求。

:::note[社区版功能开发原则 📢]
1. 若某一个功能 可以被第三方软件实现 且不与社区版产生运行冲突，原则上社区版不再实现
2. 若某一个功能在 Windows 端有，但在社区版中没有，在实现的时候 功能一般用同一个名字，用法也尽量相同，以减少使用者的学习负担
:::


### “Quicker社区版” 和原版 “Quicker” 有什么区别？
1. “Quicker社区版” 只能在 “macOS平台/部分Linux平台” 运行，“Quicker” 只能在 “Windows平台” 运行。
2. “Quicker社区版” 的功能是仿照 “Windows Quicker” 进行开发的，“Quicker社区版” 的功能滞后于“Windows Quicker”，甚至没有。
3. “Quicker社区版” 是 “Quicker” 在新平台的重新实现，技术架构和平台的不同导致动作实际运行效果和效率不同。

### “Quicker社区版” 可以运行 “Windows 端 Quicker”的动作吗？
“Quicker 社区版” 支持了 [不少常用的 Quicker 模块](/xaction/module-progress)。🌍地球在软件发布时会内置一个“由 Quicker 至 Quicker社区” 的组合动作转译组件，可以让 “Quicker动作” 在 “Quicker社区版” 上运行成为可能。

但现实是，基本不可以，Quicker 动作本质上是一个又一个的小步骤，在🌍地球实际操作时，往往一个非常小的不兼容和区别就会导致来自 Windows 动作无法运行。因此，在「Quicker 社区版」中，自己在本机制作新动作是常态。

## 版本号更新规则
“Quicker社区版”采用“明年.下月.补丁”的方式更新版本号，例如“版本2027.6”，“版本2027.6.1”。在部分场景下，为区分“Quicker”与“Quicker社区版”的版本号，也会在版本号之前加上字母“C”，其中“C”代表了“Community（社区）”，例如“C2026.6.0”。新版本总是按月发布。当前一个版本发布后，地球会创建一个新的版本号，这个新的版本号的月份部分代表了下一个新版本预计的发布月份。若前一个发布的版本有致命问题，则可能提前下一个版本的发布时间 或 在“对应更新日志”中仅发布解决问题的方式。
