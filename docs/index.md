“Quicker社区版”是一款在“macOS平台”重新开发的类Quicker软件，由社区小伙伴开发和提供支持。

“WindowsQuicker”是“Quicker社区版”的参考对象。“Quicker社区版”在一定程度上弥补了“WindowsQuicker”无法在“macOS平台”直接运行的问题。

如果你首次通过此了解到“Quicker”，那么你应该先去看一下下面的链接，那是“Windows端Quicker”的官网。

[Quicker软件 您的指尖工具箱 - Quicker](https://getquicker.net/)

如果你有PC，请你下载体验一下。如果你从“macOS相关”话题听闻到此，你也可以简单的了解一下，随后开始尝试 Quicker社区版的组合动作编辑器。

## 常见问题
### 我该如何使用“Quicker社区版”？
[安装Quicker社区版](/install)

### “Quicker社区版”和“Quicker”有什么区别？
1. “Quicker社区版”只能在“macOS平台”运行，“Quicker”只能在“Windows平台”运行。
2. “Quicker社区版”的功能是仿照“WindowsQuicker”进行开发的，“Quicker社区版”的功能滞后于“WindowsQuicker”，甚至没有。
3. “Quicker社区版”的“组合动作编辑器”的实现与“WindowsQuicker”的“组合动作编辑器”的实现不同，使用细节方面可能有细微差别。
4. “Quicker社区版”是“Quicker”在“macOS平台”的重新实现，技术架构和平台的不同导致动作实际运行效果和效率不同。

### “Quicker社区版”可以运行“Windows端Quicker”的动作吗？
“Quicker社区版”支持[大部分常用的Quicker模块](/xaction/module-progress)。虽然“Quicker社区版”是“Quicker”在“macOS平台”的重新实现，其“内部实现”与“动作定义格式”不同，但地球在软件发布时会内置一个“由Quicker至Quicker社区”的组合动作转译组件，可以让“Quicker动作”在“Quicker社区版”上运行成为可能。

[“Quicker动作”转译流程](/tech/translation)

### 我遇到了问题，从何获得帮助？
开发“Quicker社区版”的作者正在“[Quicker官方QQ群](https://getquicker.net/KC/Kb/Article/904)”水群中。

## 版本号更新规则
“Quicker社区版”采用“明年.下月.补丁”的方式更新版本号，例如“版本2026.6”，“版本2026.6.1”。在部分场景下，为区分“Quicker”与“Quicker社区版”的版本号，也会在版本号之前加上字母“C”，其中“C”代表了“Community（社区）”，例如“C2026.6.0”。新版本总是按月发布。当前一个版本发布后，地球会创建一个新的版本号，这个新的版本号的月份部分代表了下一个新版本预计的发布月份。若前一个发布的版本有致命问题，则可能提前下一个版本的发布时间 或 在“对应更新日志”中仅发布解决问题的方式。

## 术语
“Quicker社区版”也可称为“Quicker社区”，“Quicker Community Edition”， “QuickerCE”，主要作者为地球（Darcy）。

“Quicker”也可称为“Quicker原版”，“WindowsQuicker”，“Quicker（Windows）”，“Windows版的Quicker”，“Windows端Quicker”，主要作者为 CL。
