## 【安装前提醒】macOS版不支持Windows动作


### 【第一步】在本文档站中找到“版本更新”文件夹
![图：第一步](/img/docs/install/1708748214084-2e53aaba-a58d-47fd-8c91-a7372a6708fb.png)![图：第二步](/img/docs/install/1708748249770-8a5c28b5-214e-467d-a03a-0f8c3512ba6b.png)

点击最新的发布版本，例如“2027.5”，您可以在里面看到“下载地址”板块。

根据实际情况下载一种版本，现区分为 “intel版本” 与 “arm版本”，其中，“intel版本” 需要您的 Mac 搭载 Intel 芯片（通常是i5，i7 或 i9，2020年以前发布的 Mac），而 “arm版本” 要求您的Mac搭载Apple芯片（通常是 M1/M2/M3系列等 M 开头的芯片，一般为2020年以后发布的Mac）。您可以如下图中的“关于本机”查看本机的芯片架构。

查看方法：点屏幕左上角的  菜单 → **关于本机**。

![](/img/docs/install/1708249914672-8d83bb84-4c4a-4c30-88a8-19f46647ac36.png)

### 【第二步】 双击解压即可下载得到下图中的“应用程序”，请先不要打开。
<img src="/img/docs/install/1708249968884-125c9dba-4aef-4c12-8423-39186de72493.png" alt="Quicker App Logo on Desktop" width="89px" />


### 【第三步】下载并安装 “.NET 7 运行时”。

Quicker 社区版 和 Quicker Windows 版一样，支持使用 C# 表达式，为了能够运行 C# 表达式，所以我们需要安装。

官方下载地址：[https://dotnet.microsoft.com/zh-cn/download/dotnet/7.0](https://dotnet.microsoft.com/zh-cn/download/dotnet/7.0)

**在网页的靠右下的位置**，找到下图所示区域，下载对应版本安装即可。

> 请注意：安装**运行时**即可，无需安装SDK；请务必下载 .NET 7，不要安装新版本

![](/img/docs/install/1708250046415-f918ee08-26f5-4e58-a303-648f5628a632.png)

:::info[小贴士]
与上面类似的，若为 M 系列芯片，请点击下载带有 Arm64 字样的安装包，若为 Intel 系列芯片，请点击下载带有 x64 字样的安装包。
:::

:::danger[加油助力点 💪]
如果您无法打开网址或下载缓慢，在 “[Quicker交流群 QQ群 群文件](https://getquicker.net/KC/Kb/Article/904)” 中也有文件副本提供，下载对应的版本即可。

![](/img/docs/install/1708250139208-d7340df3-0c59-49de-a75a-1668639e952d.png)

:::

### 【第四步】为“Quicker社区”App添加必要的权限
+ 前往“系统设置”，为 App 添加 “**辅助功能**” 权限。这是由于 “Quicker社区版” 使用 “双击 Command 键” 等方式呼出面板。

:::note[小贴士]
在 macOS 27 中，该权限被叫做「设备控制和数据访问」。
:::


+ 为 App 添加“**屏幕录制**”权限（部分系统版本可能叫做“录屏与系统录音”等），该权限不是第一次启动时必须加的，但部分截图相关动作需要此权限，**由于该权限不可在软件运行时申请添加，因此推荐在启动软件前添加好。**

![第一步](/img/docs/install/1708250272271-940c9c8f-aa64-4253-962f-fe05de5d8e19.png)

![操作示意图](/img/docs/install/1708702557436-5764b4b1-d9ab-45fd-b7e0-77f97e2c99e2.png)

### 【第五步】打开程序
**激活与取消激活“Quicker社区版”**

您可以使用 “双击Command键” 的方式激活 “Quicker社区版”，在其他软件空白处点击一下让“Quicker社区版”失去焦点即可让“Quicker社区版”的面板消失。

## 常见问题
### 如果不安装“.NET运行时”会怎么样？
将无法打开软件, .NET 运行时在 “Quicker 社区版” 软件起到的作用是运行动作内的 “C#表达式” (也就是 $= 开头的表达式), 目前软件会在开始运行时载入表达式编译器, 所以必须先行安装, 才能正确启动.

### 如果我不给软件“辅助控制”权限会怎么样？
在第一次启动“Quicker社区版”时，由系统提示你软件需要该权限（仅会提示一次），随后报错退出软件。

### 如果我不安装“.NET 7”而安装最新的版本会怎么样？
无法打开软件。

请注意，正常来说，对于一个要求“.NET 运行时”的软件，不同版本并没有什么太大的不同，但“Quicker社区版”需要“.NET 运行时”配合内部随带的“[.NET Core 7 reference assemblies](https://www.nuget.org/packages/Microsoft.NETCore.App.Ref/7.0.16)”引用文件来编译表达式，而这些“引用”文件是版本特定的。

+ 如果你不小心安装了其他版本的 .NET，请删除下面的文件夹，然后重新安装 .NET 7 运行时

`/usr/local/share/dotnet`

📁删除指南：

1. 打开访达；
2. 按下快捷键 ![](/img/docs/install/1733113120767-c6ea28b8-ba19-45d5-8f04-e0721b08862f.png)，前往文件夹 `/usr/local/share` ；
3. 删除 dotnet 文件夹。

### macOS 系统提示「**应用程序“Quicker社区”无法打开。」**
已经按照上述流程安装, 但软件仍无法打开, 系统弹窗提示「应用程序“Quicker社区”无法打开。」 用户使用的是豆包浏览器等浏览器下载, 如有类似问题, 请尝试使用 Safari 下载,

地球这里并未发现类似问题, 目前下载的 Quicker 社区安装包本质上是 .zip 压缩包, 解压后就会得到应用程序了, 只不过 Safari 下载的时候, Safari 会自动解压(自动得到一个 .app 应用文件), 关于软件不能打开的问题, 可能是解压过程的问题.
