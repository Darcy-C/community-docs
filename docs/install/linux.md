## 【安装前提醒】社区版不支持 Windows 端动作

## 运行环境

需要同时满足下面三条：

- 图形平台须为 **X11**；
- CPU 架构为 **x86_64** 或 **arm64**；
- GLIBC 版本：**x86_64 需要 2.28 及以上**，**arm64 需要 2.31 及以上**。

:::tip[查看本机的架构和 GLIBC 版本的方法]
打开终端执行 `uname -m` 查看架构，<br>显示 aarch64 就是 arm64 的意思，amd64 和 x86_64 一个意思。


终端执行 `ldd --version` 可查看 GLIBC 版本。
:::

:::note[小贴士]
如果您从未用过 Linux 桌面，只是想在虚拟机里体验一下，建议安装 deepin 25：<br>
这个 Linux 发行版系统自带了配置好的中文环境（包括输入法），体验起来较为方便。
:::

## 支持的芯片架构

| 架构 | 适用的 CPU / 芯片 |
| --- | --- |
| x86_64 | Intel、AMD、兆芯、海光 |
| arm64 | ARM、飞腾、鲲鹏、海思麒麟 990 / 9006C / 9000C |

## 下载

[card:版本更新](../release-notes/index.md)

在最新版本页的「下载」板块里，按本机系统和架构选择 `x86_64` 或 `arm64` 的安装包，下载得到一个 `.AppImage` 文件。

## 安装

Linux 版以 AppImage 格式分发：不需要安装，给文件加上执行权限就能运行。

1. 在文件所在目录打开终端，执行下面的命令加上执行权限：

   ```bash
   chmod +x ./quicker这里按一下Tab键补全文件名
   ```

2. 双击这个文件运行。若您的系统提示需要权限，按提示允许即可。


## 已验证的平台

以下平台已实际跑通，可以作为参考：

- deepin 25
- 统信 UOS 20（x86_64）
- 统信 UOS 25
- 麒麟 V10

同一架构下的其它发行版（例如满足 X11 + GLIBC 要求的 Ubuntu）一般也能运行，可以下载对应架构的安装包试一下。

## 已知无法运行的平台

| 平台 | 原因 |
| --- | --- |
| 麒麟 V11 | 该系统不使用 X11，且无法切换回 X11 |
| 统信 UOS 20（arm64）| 该系统的 GLIBC 版本为 2.28，而 arm64 架构下最低要求 GLIBC 2.31，因此无法使用 |
| 纯 Wayland 桌面的系统 | 一般信创系统不提供切换到 X11 的能力；部分社区发行版的最新版已移除 X11 组件，需要手动安装 |

## 常见问题

### 双击软件后提示「没有可打开的应用」等说法

一般是文件没有执行权限导致的，按上面「安装」一节的 `chmod +x` 处理即可。

### 无法运行或报错

- 统信 UOS 用户请先检查「安全中心」→「安全工具」是否已切换为「允许任意应用」（其他系统或者不同版本，也可能有类似的开关，但可能在不同位置，请找到后开放权限）
- 其它系统请确认 GLIBC 版本是否达到要求（x86_64 需要 2.28 及以上，arm64 需要 2.31 及以上），以及当前桌面是否为 X11。
