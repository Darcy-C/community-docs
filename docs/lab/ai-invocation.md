---
title: 🧪 酷调用（智能调用）
sidebar_position: 3
---

用一句自然语言描述你要做的事，模型会从**面板里的动作**中挑出合适的，生成参数并把它们排成执行序列。旧名字叫「MCP」。

**平台：全平台**（只要联网）。实验功能，默认关闭。

## 开启与使用

1. **设置 → 关于 Quicker → 实验室 → 酷调用**，打开开关。
2. 打开搜索面板，直接输入你的需求，例如：
   - `把刚才复制的文字翻译成英文`
   - `截图并识别里面的文字`
3. 结果列表顶部会出现一条 **🔮 <你输入的描述>**，点它就进入规划。
4. 规划完成后，列表变成若干行「要运行动作」；点 **🔮 运行** 会按顺序执行，点击单行则只跑那一个。

## 它是怎么规划的

1. 收集**当前面板里所有动作**的名字、描述，以及它们声明的输入/输出变量。
2. 把这些信息连同你的需求发给语言模型（智谱 `glm-4-flash`），流式返回「运行"动作名"」这样的行。
3. 对需要参数的动作，再单独请求一次生成参数（JSON），最后汇总成一段说明。
4. 执行时逐个动作串行运行，每个之间等 200 ms，并等上一个跑完。

## 限制（重要）

- **读不到动作的输出**：只能「触发动作」，无法把一个动作的结果交给下一个动作。需要串联数据时请用子程序。
- 只认识**面板里放着的动作**，动作库里有但没放进面板的不会被选中。
- 依赖**硬编码的第三方 API Key** 与网络，不允许自己填 Key；服务方限流或不可用时，规划会直接失败。
- 失败通常**没有界面提示**，只有日志；表现为「点了没反应」。
- 规划结果不一定正确，执行前请看一眼它挑的动作。

:::warning

这是实验功能：接口、模型、可用性都可能随时变化，不建议把它放进日常依赖的工作流。

:::
