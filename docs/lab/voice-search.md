---
title: 🧪 语音搜索
sidebar_position: 1
---

在搜索框里**按住 `⌘ Space` 说话**，边说边把识别结果填进输入框；松开后自动执行搜索结果里选中的那一项。

**平台：仅 macOS**（使用系统 `AVAudioEngine` + `SFSpeechRecognizer`）。Linux 上开关仍然存在，但不会工作。

## 开启

1. **设置 → 关于 Quicker → 实验室 → 语音搜索**，打开开关。
2. 打开搜索面板（默认 `Ctrl Space`，或从面板中栏菜单选「搜索动作」）。
3. 在输入框里按住 `⌘ Space` 开始说话，松开结束。

## 行为细节

- 使用中文识别（`zh-CN`），带标点、返回中间结果，因此输入框里的文字会边说边变。
- 松开后延迟约 **500 ms** 再结束，避免最后一个字被截断；如果输入框里已有文字，会直接执行当前选中的结果。
- 识别结果只是**填进输入框**，不会自动执行动作——和手动打字搜索完全等价。

## 依赖与坑

| 项目 | 说明 |
| --- | --- |
| 麦克风权限 | 首次使用会请求；拒绝后需要到「系统设置 → 隐私与安全性 → 麦克风」手动打开 |
| 语音识别权限 | 系统会请求「语音识别」授权，同样在隐私与安全性里 |
| 网络 | 默认走系统语音识别，可能是**在线识别**（代码没有强制离线），断网时容易失败 |
| 失败表现 | 只把错误打到日志，界面不会有提示；表现为「按住没反应」 |

:::warning

如果按住了完全没有反应：先确认开关是打开的，再看系统里麦克风/语音识别两项是否都允许，最后重启一次应用。

:::
