## 2027.5.2

(更新时间： 2026 年 10 月 9 日晚)

:::info[**Quicker 社区版开发路线和原则**：将进一步深入优化细节性体验，核心功能以逐步进入稳定期（类似于 Windows Quicker V1 时代）。从历史上看，细节性优化稳定期是重要的软件体验组成部分，地球将深入研究每一行内部代码，坚持不懈长期打磨。]
**Quicker 社区版是否开展属于社区自己的 V2 时代？**：目前仍处于观望期，短期内不会。

:::

**本次更新核心看点：「共享子程序」概念**

1. 【其他页面更新】地球第三方 macOS 应用推荐页已更新：macOS 效率软件分享（该页面未迁移到本站）
2. 为 子程序 的每个参数编辑框提供一个工具菜单 （例如 选择界面元素）
3. 其他综合优化与重构（由 AI 完成，可能存在额外的不确定性，将持续人工检查）
4. 支持「共享子程序」概念，该概念的实现方法与 Windows Quicker 有所不同，使用方式 和 具体不同点 如下：

**使用方式**：请见下方图片，随后点击「从其他动作复制」后按引导操作即可。

![🍟 功能示意图](/img/docs/release-notes-2027/1791372196403-3e5b472a-26f9-45bf-8da3-401dd4e5023e.png)

**具体不同点**：社区版使用「复制」这一概念，当子程序从其他动作中完成复制后，相当于自行编写的，<u>复制后的子程序和原始子程序可以没有关联且就是正常的蓝色内部子程序</u>。如果需要做所谓的同步或更新的效果，您可以重新复制，那个时候就会提示是 **更新**了（社区版中子程序内部有 子程序 ID 做识别的，复制的子程序和原来的子程序有同一个 ID，所以可以做到这个更新效果），那么这样一来我们可以手工决定何时更新（就类似于 Windows Quicker 中的网络子程序的更新方法了），如果我们想要批量更新（例如有一个子程序叫做：等待并点击，想批量更新下去做一个覆盖），我们可以用设置里的批量更新功能，请见下图：

![🍔 功能位置示意图](/img/docs/release-notes-2027/1791372590202-8075d457-d3a2-49d0-8843-46ea65763c97.png)

（完成更新后，子程序定义完成同步，可自行选择哪些更新，哪些不更新）

那么通过这几个方法，我们可以做到以下**优势和变化**：

1. 语义上讲是复制，更好理解
2. 可以单独给 1 个动作更新（直接在动作编辑器内操作，再复制一次，界面会提示本次为**更新**）
3. 可以在设置中批量把 1 个上游的更新批量下发下去（在设置里提供了按钮）
4. 用户可以相信，只要自己不想更新，那个用了子程序的动作永远不会损坏（不自动同步定义）
5. 所谓的公共子程序现在可以放在任何一个动作里，可以根据心情分类到自己的动作
6. 自己的子程序按照动作进行分类后，可以在那个动作做一些自己的尝试和测试，其他动作按照动作名正常去导入（也就是复制了）

## 2027.5.1

（发布时间：2026 年 10 月 3 日下午）

1. 组合动作编辑器的大小将会被记忆（仅记忆窗口大小），方便个人对大小喜好进行微调并记忆。
2. 新增「调用 DeepSeek」模块。填写 API Key 与 提示词 后便可使用。提供简单的内置提示词模板功能。

注明：考虑到实际可用性，由于模块一般为阻塞使用（模块不断运行导致 AI 返回），为确保生成速度，思考模式已关（内部已写死并暂不开放为参数），建议使用时尽量让 AI 以简短的格式返回（而非 markdown 这样的格式），AI 返回速度与回复长度高度相关，如果可能，建议在提示词内就限定大致长度。

3. 新增「切换系统主题」模块。用于切换 亮色/暗色/取反切换。
4. 新增「控制界面元素」模块。与 Windows Quicker 的窗口界面控制概念上相同。

核心技能：基于辅助控制能力定位元素，也整合了其他的正常模拟按键能力。

模块使用建议：先试试本模块，如果完全不行，则使用其他方案（纯键鼠/找图），如果部分可行或暂时完全可行，可搭配其他模块一起使用。有的时候可能一个操作需要分成多步操作，也就慢慢可以自动化操作了，可视实际情况测试和权衡。
