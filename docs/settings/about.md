## 这个页面有什么

- **版本号**：形如 `C2027.6.0`，反馈问题时请带上它。
- **按键状态**：Quicker 内部认为当前按下的键盘键、鼠标键（中键/X1/X2），以及 macOS 上的触控板手指数。
- **致谢 / 隐私**：开源组件与隐私说明。

## 按键状态页怎么用

1. 按下想测试的键或鼠标侧键，观察状态区是否会亮起。
2. 没有任何反应时，先确认系统层面的权限：
   - **macOS**：系统设置 → 隐私与安全性 → **辅助功能**，勾选「Quicker社区版」，然后**重启软件**。
   - **Linux**：确认当前是 X11 会话（`echo $XDG_SESSION_TYPE`），Wayland 下收不到全局输入。
3. 状态卡住（显示按下但其实已松开）时，点 **重置键盘状态**。

:::note

有些鼠标厂商的驱动会先把侧键吃掉，Quicker 收不到事件。这类情况需要在厂商驱动里把侧键映射为「普通按键」或在驱动里关闭宏功能。

:::

:::tip[触控板（仅 macOS）]
放置四指看检测数量是否正确，再四指轻点看面板是否弹出。手指数检测不准时，四指触发面板会失效。
:::
