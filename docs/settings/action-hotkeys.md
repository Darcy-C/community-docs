给**单个动作**绑定系统级快捷键，不管当前在哪个应用里都能直接运行。

<img class="qk-shot" src="/img/docs/settings/action-hotkeys/light.webp" data-dark="/img/docs/settings/action-hotkeys/dark.webp" alt="动作全局快捷键" />

## 用法

1. 点 **添加动作快捷键…**，选择动作并按下想用的组合键。
2. 每条规则可以单独**启用/停用**（右侧开关），方便临时让出键位。

:::note[和「面板动作触发键」的区别]
- 这里绑定的是**全局**快捷键，任何应用在前台都生效。
- [面板动作触发键](/settings/panel-keys) 只在面板打开时生效。
:::

:::tip

快捷键尽量带修饰键（`⌃⌥` 等）。与系统或常用软件冲突时，表现为「谁先拿到键谁执行」，不会有提示。

:::
