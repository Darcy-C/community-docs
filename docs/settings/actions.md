场景（Scene）就是面板上的一「页」动作。场景名与前台应用的名称匹配时，面板会自动切换到该场景。

<img class="qk-shot" src="/img/docs/settings/actions/light.webp" data-dark="/img/docs/settings/actions/dark.webp" alt="动作与场景管理" />

## 内置场景

| 场景 | 说明 |
| --- | --- |
| **全局** | 永远显示在面板上半部分，与前台应用无关 |
| **常用** | 没有任何场景匹配当前前台应用时，显示在面板下半部分 |

这两个是内置场景，**不能删除也不能重命名**（尝试时会有提示）。

## 可以做什么

- **新建 / 重命名 / 删除场景**：自定义场景名建议直接写成前台应用的名称（例如 `Safari`），这样切到该应用时面板会自动显示这一页。
- **调整页面顺序**：移到最前、移到最后、在当前页前/后插入。
- **清空场景**：删除场景会提示该页里还有动作，确认后一起删除。
- **拖动排序动作**：在面板里直接把动作拖到目标位置即可。

:::note

场景页面数量的上限和动作容量与面板布局有关；一页放不下的动作请分页，而不是缩小按钮。

:::
