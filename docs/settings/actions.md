所谓场景，就是前台软件是什么，前台软件名字不同，就显示不同的内容。在 Quicker 中，面板上半部分显示「全局」场景，下半部分显示前台软件名字对应的场景，如果没有设置对于的场景，就显示「通用」，前台应用的场景名称匹配时，面板会自动切换到该场景。

## 内置场景

| 场景 | 说明 |
| --- | --- |
| **全局** | 永远显示在面板上半部分，与前台应用无关 |
| **通用** | 没有任何场景匹配当前前台应用时，显示在面板下半部分 |

这两个是内置场景，**不能删除也不能重命名**（尝试时会有提示），您可以创建自己的场景，当场景名字和前台软件名字对上时（系统左上角），则会自动在下半部分显示。

## 可以做什么

- **新建 / 重命名 / 删除场景**：自定义场景名建议写成前台应用的名称（例如 `Safari浏览器`），这样切到该应用时面板会自动显示这一页。
- **调整页面顺序**：移到最前、移到最后、在当前页前/后插入。
- **清空场景**：删除场景会提示该页里还有动作，确认后一起删除。
- **拖动排序动作**：在面板里直接把动作拖到目标位置即可。
