面板、轮盘、动作按钮的配色与尺寸都在这里，**明暗主题分别保存**：先在页面顶部切换到「当前明亮主题 / 当前暗黑主题」，再调整。

## 面板

| 设置项 | 说明 |
| --- | --- |
| 面板尺寸 / 按钮大小 / 按钮间距 / 圆角 | 决定面板整体观感，按钮过大时一页能放的动作会变少 |
| 面板边框宽度 | 面板外框粗细 |
| 面板背景色 / 工具栏背景色 / 工具栏前景色 | 支持带透明度的颜色 |
| 面板背景图 | 本地路径或 http(s) 图片地址，配合「不透明度」使用 |
| 动作矢量图标颜色 / 图标背景色 / 图标字体颜色 | 影响所有动作按钮的图标与首字母 |
| 空白动作图标背景色、触发键文字颜色 | 未放置动作的格子、面板动作触发键的字色 |

## 轮盘

- 轮盘尺寸、背景色、分割线颜色、指示线颜色、动作文字颜色、动作图标颜色。

## 其他

- **隐藏面板动作标签**：只显示图标，面板更紧凑（图标识别度高时推荐）。
- **应用字体**：修改全局字体，**部分控件需要重启软件**才完全生效。
- **恢复**：把当前主题的所有外观设置恢复为默认值。

:::tip

改完某一项如果看不到效果，先切换一次明暗主题再切回来，可以让面板重新取色。

:::
