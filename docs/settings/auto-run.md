使用 **cron 表达式** 定时运行动作，不需要任何手动触发。适合定时备份、定时提醒、定时刷新页面之类的场景。

<img class="qk-shot" src="/img/docs/settings/auto-run/light.webp" data-dark="/img/docs/settings/auto-run/dark.webp" alt="自动运行动作" />

## 规则怎么加

1. 点 **添加定时任务…**，选择动作。
2. 设置时间。界面用一个六段式 cron 表达式保存：`秒 分 时 日 月 周`（与标准 crontab 相比**多了「秒」段**）。
3. 列表里会显示「距离下次触发还有多久」，可随时启用/停用、编辑、删除、拖动排序。

常用写法：

| 目标 | 表达式 |
| --- | --- |
| 每小时整点 | `0 0 * * * *` |
| 每天 9:30 | `0 30 9 * * *` |
| 每周一 10:00 | `0 0 10 * * 1` |
| 每 5 分钟 | `0 */5 * * * *` |

:::note

定时任务只在 Quicker 正在运行时生效；电脑睡眠期间不会补跑，唤醒后按下一次到点时间执行。

:::

:::tip

需要「唤醒后立即执行」的效果，用 [事件触发](/settings/event-triggers) 而不是定时任务。

:::
