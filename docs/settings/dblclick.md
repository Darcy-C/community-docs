在系统范围内**双击同一个按键**（例如连按两下 `⌥`）来触发动作。

<img class="qk-shot" src="/img/docs/settings/dblclick/light.webp" data-dark="/img/docs/settings/dblclick/dark.webp" alt="按键双击" />

## 用法

1. 点 **添加规则…**，选择要双击的键与目标动作。
2. 每条规则可单独启用/停用，并可写备注显示在列表里。

:::note

双击的判定窗口是固定的「两次按下间隔」，太快或太慢都不算。选修饰键（`⌥`、`⌃`、`⌘`、`⇧`）最不干扰正常输入。

:::
