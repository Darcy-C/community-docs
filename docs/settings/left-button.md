title: 左键辅助

**按住左键 + 另一个键** 触发动作。不用离开鼠标就能执行，适合「选中文字后处理」「按住左键时呼出工具」这类操作。

<img class="qk-shot" src="/img/docs/settings/left-button/light.webp" data-dark="/img/docs/settings/left-button/dark.webp" alt="左键辅助设置" />

## 规则字段

| 字段 | 说明 |
| --- | --- |
| 触发键 | 与左键同时按住的那个键（鼠标按住左键时按这个键） |
| 动作 ID | 要运行的动作；可从面板动作的右键信息里复制内部 ID |
| 触发后提示 | 触发后弹出的提示文字，留空则不提示 |
| 备注 | 只给自己看的说明 |

## 使用方式

1. 点 **添加左键辅助…**，选触发键与动作。
2. 按住鼠标左键（或在触控板上按住不放），再按设定键，动作即被触发。

:::note

在 macOS 触控板上，按住不放会被识别为左键按住；如果同时开启了「三指拖移」之类的系统手势，可能会抢占按键，需要先在系统设置里调整。

:::

:::warning

触发键不要选系统常用组合（如 `⌘C`、`⌘V`），也尽量不要选会与拖拽冲突的键，否则拖选文字时会误触发。

:::
