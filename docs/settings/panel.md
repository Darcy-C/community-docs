控制**如何呼出动作面板**。外接鼠标时用鼠标方式更顺手，只用触控板时用键盘方式。

<img class="qk-shot" src="/img/docs/settings/panel/light.webp" data-dark="/img/docs/settings/panel/dark.webp" alt="弹出面板设置" />

## 鼠标方式

| 触发方式 | 说明 |
| --- | --- |
| 按中键 / 按 X1 键 / 按 X2 键 | 鼠标中键、侧键；X1/X2 需要鼠标驱动不拦截 |
| Ctrl + 中键单击 / Ctrl + 右击 | 组合触发，减少误触 |
| Command + 中键单击 / Command + 右击 | **仅 macOS** |
| 长按中键 / 长按右键 | 按住超过阈值才触发 |
| 按右键移动 | 按住右键拖动一段距离后触发 |
| 松开后触发 | 开启时在按键抬起瞬间触发；关闭时按下即触发 |

## 键盘方式

| 触发方式 | 说明 |
| --- | --- |
| 单击 Ctrl 键 | 单独点一下 Ctrl（左右任一） |
| 双击 Command 键 | **仅 macOS** |
| 忽略左侧 Command 双击 | 避免左 ⌘ 常见组合键误触发 |
| 全局快捷键 | 自定义任意组合键 |

## 触控板方式（仅 macOS）

- **四指轻点**：四指快速点击一次触控板。

:::note[平台差异]
Linux 下没有 Command 键与触控板选项，鼠标侧键也取决于 X11 是否能收到（部分驱动会吞掉 X1/X2）。
:::

:::tip[建议]
同时开「中键」+「Ctrl + 中键」是最省心的组合：日常单击中键，需要精确时用组合键。若经常误触，加「松开后触发」或改用长按。
:::
