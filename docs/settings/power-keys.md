把**普通键当作组合键的引导键**：先按住引导键 → 再按动作键 → 松开引导键，执行动作。

<img class="qk-shot" src="/img/docs/settings/power-keys/light.webp" data-dark="/img/docs/settings/power-keys/dark.webp" alt="扩展热键" />

## 规则字段

| 字段 | 说明 |
| --- | --- |
| 引导键 | 按住不放的那个普通键 |
| 动作键 | 引导键按住期间按下的键 |
| 动作 | 要执行的动作 |
| 白名单应用 | 只在该应用前台时生效，留空表示全局 |
| 提示消息 | 触发后弹出的提示 |
| 备注 | 给自己看的说明 |

## 为什么 Linux 没有这一页

地球把握不住，暂时实现不了。

:::tip

和 [按键双击](/settings/dblclick) 的区别：扩展热键是「按住引导键 + 另一个键」，按键双击是「同一个键点两下」。

:::
