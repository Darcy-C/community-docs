把**普通键当作组合键的引导键**：先按住引导键 → 再按次键 → 松开引导键，执行动作。

<img class="qk-shot" src="/img/docs/settings/power-keys/light.webp" data-dark="/img/docs/settings/power-keys/dark.webp" alt="扩展热键" />

## 规则字段

| 字段 | 说明 |
| --- | --- |
| 引导键 | 按住不放的那个普通键 |
| 次键 | 引导键按住期间按下的键 |
| 动作 | 要执行的动作 |
| 白名单应用 | 只在该应用前台时生效，留空表示全局 |
| 提示消息 | 触发后弹出的提示 |
| 备注 | 给自己看的说明 |

## 为什么 Linux 没有这一页

引导键必须做到「按下先吞掉，如果后面没有次键再补发原键」。X11 的被动抓取只能整键拦截，无法在松开时安全回放，因此 Linux 上该功能不可用：**设置页里整个「扩展热键」条目会被移除**，监听器也不会启动。

:::warning

引导键要慎选：它会在全局范围内被短暂抢占。选字母键时，正常打字可能有轻微延迟感；选 `Caps Lock`、右侧修饰键这类平时不用的键更稳。

:::

:::tip

和 [按键双击](/settings/dblclick) 的区别：扩展热键是「按住引导键 + 另一个键」，按键双击是「同一个键点两下」。

:::
