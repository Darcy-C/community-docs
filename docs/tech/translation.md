---
title: “Quicker 组合动作”转译流程
sidebar_position: 5
---

把 Windows 版 Quicker 的动作（`.qka` / 分享链接）转换成社区版能运行的格式。转换在**内存里**完成，不落中间文件。

:::warning[转译不等于能用]
转换只解决「动作定义格式」这一层。社区版没有实现的模块、平台专属的模块（AppleScript、Vision、注册表等）转过来仍然是空的，实际运行时多半要自己重写对应步骤。**别指望 Windows 动作导入后直接跑通。**
:::

## 入口

| 入口 | 说明 |
| --- | --- |
| 粘贴分享链接 | 在面板**空按钮**上右键粘贴 `https://getquicker.net/Sharedaction?code=...`，会联网下载并转换 |
| 拖入本地文件 | 把本地导出的分享 JSON 拖进面板（需要是带 `Data` 键的分享记录，裸 `qka` 不接受） |
| URL 协议 | `quicker:previewaction:<分享码>`（仅 macOS），转换后直接在编辑器打开 |
| 反向导出 | 动作右键可导出为 `qka`，也可以分享回 getquicker.net |

## 流程

```text
分享链接 / 文件
      ↓
GetSharedActionByLink 接口（或本地 JSON）
      ↓
translate()：逐步骤映射模块 key、转换变量类型
      ↓
直接写入 sqlite（actions 表）
```

转换后存的是社区版自己的动作数据；**不会生成也不会保存 `qka` 文件**。

## 转换时会掉的东西

| 项目 | 处理方式 |
| --- | --- |
| 变量类型 | 键盘/鼠标/枚举/表单/对象等上游类型统一降级成 `any`，不报错 |
| 未实现的模块 | 保留 key 与参数值，但界面上会隐藏模块，运行时不可用 |
| 平台标记 | 转译结果一律标记为 `windows` |
| 网络子程序 | 未实现（代码里是明确的 TODO），只按**本地名字**匹配子程序 |
| 子程序内容 | 只映射引用，不会自动补全缺失的子程序 |

## 什么时候会失败

- 分享码无效、网络不通、接口返回空。
- 本地文件不是分享记录格式（缺少 `Data` 包裹）。
- 动作里用了社区版完全没有的模块——不会失败，但运行时那一步会报错/被跳过，请对照 [模块实现进度](/xaction/module-progress)。

## 转译后建议做的事

1. 打开动作，逐个检查被隐藏参数的步骤（编辑器里会显示为默认值）。
2. 把「运行脚本」「浏览器控制」「输入法控制」这类平台专属模块换掉（macOS 可用、Linux 不可用）。
3. 用 [模块实现进度](/xaction/module-progress) 核对每个模块在目标平台是否 ✅。

:::note

窗口版「实时同步/更新共享动作」的概念在社区版里没有实现：转译进来的动作就是一份独立副本。

:::
