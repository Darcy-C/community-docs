当前版本是 **C2027.6.0**。

## 下载

本版本还没有对外安装包；有包后会更新在这一页。

## 本次更新

主线是 **Linux（X11）支持**与编辑器体验打磨。Linux 版以 AppImage 形式提供，macOS 包与以往一致。

## 新增：Linux（X11）支持

- 完成 X11 移植：全局键盘/鼠标监听、取色、截图等核心能力在 X11 会话下可用。
- 打包为 **AppImage**（`quicker-ce-C2027.6.0-linux-x86_64.AppImage`），内置 fcitx5、.NET 与 Roslyn 依赖。
- 限制：**Wayland 会话无法监听或拦截全局输入**；扩展热键整页隐藏；事件触发只支持「应用激活」。

## 设置与系统集成

- macOS 27：运行动作前**强制恢复上一个窗口的焦点**（新系统行为变化所致，选项变为只读）。
- 设置窗口在 Linux 下的背景与边距适配，导航栏按平台隐藏不可用条目。

## 编辑器与步骤参数

- 「正则提取」增加**正则测试器**，可在步骤里直接试匹配结果。
- 参数选取器补齐：路径、颜色、字体、子程序参数可以直接挑选。
- 「按键操作」支持「录制单个按键」。
- 布尔参数显示为勾选框；未手工设置时保持手动输入状态，不再被默认值覆盖。
- 步骤描述与参数文本编辑器的导入排序、按钮尺寸等细节修正。

## 其他

- WebView 窗口在失焦时支持隐藏 / 最小化。
- 文本指令可以「匹配到缩写后运行动作」（不仅发送文本）。
- 一批 i18n 文案补全与翻译，包括文本指令编辑器、面板对话框。

## 版本号规则

版本号形如 **`明年.下月.补丁`**，例如 `2027.6.0` 表示「2027 年、预计 6 月发布的小版本、第 0 个补丁」。

- 前一个版本发布后，会立刻把下一个版本的「月份」定下来，代表**预计发布月份**。
- 为了和 Windows 版 Quicker 的版本号区分，社区版常在前面加字母 `C`，例如 `C2027.6.0`。
- 补丁位（第三段）只修问题不加功能；`0` 表示该小版本的第一个正式构建。
