---
title: 获取选中的文本
sidebar_position: 17
---

取到当前应用里**已选中的文字**。实现方式是「复制」，因此会动到剪贴板。

## 它是怎么实现的

1. **先清空剪贴板**，再模拟复制（macOS `⌘C`，Linux `Ctrl+C`），然后轮询剪贴板最多 「等待超时」 毫秒。
2. 拿到内容后按「文本数据格式」取对应格式（纯文本 / Rtf / Html / CSV）。
3. 超时仍为空则失败：`无法获取选中的文本`。

:::danger[原来的剪贴板内容不会恢复]
步骤会先清空剪贴板。如果复制失败（目标应用不支持复制、没有选中内容），**你原来的剪贴板就没了**。需要保留时，先自己用「剪贴板」相关步骤备份。
:::

## 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 使用动作参数 | 关 | 直接从动作参数取文本，完全不碰剪贴板；用于被其他动作/外部调用时 |
| 格式 | UnicodeText | 纯文本 / Rtf / Html / CSV |
| 等待超时 | 250 ms | 每 10 ms 轮询一次 |
| 去除首尾空白 | 开 | |

## 输出

| 输出 | 说明 |
| --- | --- |
| 内容 | 取到的文本 |
| 「去除封装的 HTML」 | 只保留 `StartFragment`~`EndFragment` 之间的 HTML |
| 来源网址 | 文本里出现的第一个链接 |
| 「URL 编码的内容」 | 百分号编码后的文本（拼 URL 用） |
| 是否成功 | |

## 平台

macOS 与 Linux 都支持（复制快捷键按平台自动切换）。前提是目标应用允许复制——终端、某些自绘界面的应用经常拿不到。

:::tip

网页里选中的文字，用 [浏览器控制](/xaction/browser-control) 的元素读取往往比「复制」更可靠（仅 macOS）。

:::
