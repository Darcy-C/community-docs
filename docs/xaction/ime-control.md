切换 macOS 的输入法状态。**仅 macOS**，Linux 版隐藏。

## 操作

| 操作 | 实际行为 |
| --- | --- |
| 禁用输入法 | 切换到系统内置的 **ABC** 输入源 |
| 启用输入法 | 切换到 **简体拼音** |
| 获取状态 | 当前是不是「简体拼音」 |
| 恢复 | 回到本步骤之前记住的那个输入源 |

## 限制（很重要）

- 它只认 **ABC** 与 **简体拼音** 两个系统输入源，名字是硬编码的。系统语言不是中文/英文时，这两个名字对不上，操作会**静默失败**（返回 false，但步骤不报错）。
- **第三方输入法**（搜狗、微信、Rime 等）无法通过本模块切换或记忆。
- 「启用/禁用」切换的是输入法**引擎**，不是中英文状态；想在中英之间切换，用快捷键更可靠。
- 「恢复」依赖本次运行记下的输入源，单独使用没有意义。

## 什么时候有用

- 输入密码前强制切到 ABC。
- 用完 OCR/粘贴后把输入法恢复成拼音。

:::tip

需要「切换到自己指定的某个输入法」目前还不支持。变通做法：用「模拟按键」发送系统切换输入法的快捷键（默认 `⌃ Space` 或 `⌘ Space`，取决于你的系统设置）。

:::
