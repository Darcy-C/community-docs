在任意文本参数里用 `{变量名}` 把变量值填进去，是最常用的「取值」方式。

## 三种前缀

| 写法 | 含义 |
| --- | --- |
| `{变量}` | 普通插值（文本替换） |
| `$$` | 布尔插值：把一段**文本表达式**转成布尔（`true/false`、`1/0`、`yes/no` 等字面量，其他非空字符串也有对应规则） |
| `$= ...` | C# 表达式 |
| `@= ...` | Python 表达式（内置解释器，能力受限） |

`$$` 并不是某一两个模块的专属语法：**任何参数**只要按布尔解析，都会走这套转换。

## 索引与取值（2027.4.3 起）

```text
{列表.0}        {列表[0]}
{词典.key}      {词典["key"]}
```

支持点号与方括号两种写法，可以连续取。

## 取不到时不会报错

`{nope}`、`{列表.不存在的key}` 会**原样保留**在字符串里，方便你直接看出哪里配错了。所以「输出里出现了花括号」通常就是变量名写错或还没赋值。

## 与表达式的区别

| | 插值 `{}` | 表达式 `$=` / `@=` |
| --- | --- | --- |
| 用途 | 拼字符串 | 计算、判断、调用方法 |
| 失败 | 保留原文 | 按「失败时中止」决定是否中断 |
| 类型 | 一律转字符串 | 保留/转换类型，见 [变量](/xaction/variable) |

## 注意

- 变量名区分大小写。
- 图片变量插值出来是一个占位描述，不能当路径用。
- 表达式在**步骤的输入参数**上执行；输出变量名不支持表达式。
