---
title: 按键操作
sidebar_position: 12
---

直接按下/松开某个键，或读取按键状态。和 [模拟按键](/xaction/simulate-key) 的区别：这里可以**按住不放**。

## 参数

| 参数 | 说明 |
| --- | --- |
| 操作 | 按下 / 松开 / 获取按键状态 |
| 按键 | **必填 macOS 虚拟键码（整数）** |
| 保持时长 | 仅「按下」有效：大于 0 时到点自动松开；等于 0 表示**一直按住**，直到后续步骤显式松开（默认 1000 ms） |

## 典型用法

```text
按键操作：按下 ⇧（保持 0）
模拟按键：A            → 得到 ⇧A 按住效果
按键操作：松开 ⇧
```

选中文本、按住修饰键拖拽、按住鼠标改键这类「过程性操作」都得靠它。

## 注意

- **按键必须是数字键码**。传字符串 `"enter"` 不会被当成回车键：会被当成一串字符去输入。键码从动作编辑器里的按键选择器取最稳。
- 「获取按键状态」只对 **Caps Lock** 有意义，其他键恒为 false。
- 默认 1000 ms 的「保持时长」意味着不填也会自动松开；要长时间按住必须显式填 0。
- 忘了松开会导致修饰键一直处于按下状态，表现为后续所有输入都带修饰键——记得在动作末尾补「松开」。

## 平台

macOS 与 Linux 都支持（Linux 用 X11 读取 Caps Lock 状态）。
