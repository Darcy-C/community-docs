从图片里识别文字，基于 macOS 系统视觉框架（Vision），不需要额外下载模型。

**平台：仅 macOS**，Linux 版隐藏该模块。

## 参数

| 参数 | 说明 |
| --- | --- |
| 图片 | 图片变量 |
| 语言 | 中文+英文 / 英文 / 韩文 / 日文 / 繁体中文 / 拉丁 / 阿拉伯；留空则由系统自动判断（不可靠时回落到中英） |
| 离线模式 | ❌ 未实现，界面隐藏 |
| 失败时中止 | |

## 输出

| 输出 | 说明 |
| --- | --- |
| 合并后结果 | 所有识别结果**直接拼接**的字符串（没有换行分隔） |
| 「行列表」 | 按识别块拆分的列表 |
| 原始结果 | 每块的位置、文本与置信度 |

:::warning[拼接没有分隔符]
「合并后结果」是把各块结果直接相加的，语义上相当于「一段话」。需要按行/按块处理请用 「行列表」 或 「原始结果」。
:::

## 注意事项

- 语言纠错是**恒定开启**的，无法关闭。
- 识别质量高度依赖截图分辨率与缩放比：不同机器、不同 DPI 下同一界面可能出不同结果，所以 OCR 结果适合「自用」，不适合做严格断言。
- 图片里没有文字时不会报错，返回空字符串。
- 已移除的旧参数：「接口」「标点符号转换」「合并段落」在当前版本里都不存在了。

:::tip

OCR 慢且吃 CPU。整屏识别前先裁剪出目标区域（[屏幕截图](/xaction/screenshot) 的固定区域模式），能显著提速。

:::
