title: 播放声音
sidebar_position: 24
---

播放内置提示音、外部音频文件，或用系统语音朗读一段文字。

## 三种模式

| 模式 | 说明 |
| --- | --- |
| 本地内置音 | 应用自带的提示音 |
| 外部文件 | 本地路径**或 http(s) 链接**（远程文件会先下载到临时目录再播放） |
| 文字转语音 | macOS 用系统 `say`，Linux 用内置 TTS；遵循「等待」设置 |

## 参数

| 参数 | 说明 |
| --- | --- |
| 等待播放结束 | **默认开启**，即步骤会等到播放完才继续 |
| 音量 | |

:::note[关于内置音]
「截图」音和「警告」音目前都指向同一个 `warning.wav`，听感上没有区别。
:::

## 播放不会被动作结束打断

声音由进程内的播放器统一持有，引用会保留到播放结束。因此：

- 以前「动作结束时声音被截断、需要在后面加等待」的说法**已经过时**。
- 不勾「等待播放结束」也能完整播完（异步返回，播放继续）。
- 勾了「等待」则步骤会一直阻塞到音频播完——长音频要注意。

## 平台

macOS 与 Linux 都支持；两个平台的内置音与 TTS 实现不同，实际音色会有差异。
