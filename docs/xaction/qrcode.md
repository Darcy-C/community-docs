用系统视觉框架从图片里识别二维码和条形码。

**平台：仅 macOS**（Vision 框架），Linux 版隐藏该模块。

## 参数与输出

| 参数 | 说明 |
| --- | --- |
| 图片 | 图片变量（一般来自截图） |

| 输出 | 说明 |
| --- | --- |
| 值 | 识别到的内容，多个结果用换行拼接成一个字符串 |
| 「全部二维码值」 | 结果**列表**（要逐个处理时用这个） |
| 「条码类型」 | 第一个结果的码制（QR、EAN13 等） |

## 注意

- 它不是「只认二维码」：底层没有限制码制，常见的条形码也能识别。
- **没识别到不会报错**：输出为空、「是否成功」仍是成功。需要判断请检查「值」是否为空。
- 传入的不是图片变量会直接报错。
- 识别在 UI 线程执行，超大图会短暂卡界面。

:::tip

先 [屏幕截图](/xaction/screenshot) 框选二维码区域，再交给本模块，识别率比整屏识别高很多。

:::
