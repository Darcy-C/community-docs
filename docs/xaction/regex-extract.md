---
title: 正则提取
sidebar_position: 10
---

用正则从文本里提取内容。语法是 **Python `re`**，不是 .NET，`.NET 专属写法（如 `\p{L}`）在这里不成立。

## 参数

| 参数 | 说明 |
| --- | --- |
| 文本 | 要匹配的内容 |
| 正则 | Python 正则 |
| 取哪部分 | `0` 整个匹配值 / `1` 第一个匹配的组 / `2` 每个匹配的组 |
| 单行模式 | `re.DOTALL`：`.` 匹配换行 |
| 多行模式 | `re.MULTILINE`：`^`/`$` 匹配每行 |
| 从右往左 | 结果列表**反转**（不是真正的从右扫描） |
| 失败时中止 | |

## 输出

| 输出 | 说明 |
| --- | --- |
| 匹配结果 1 ~ 5 | 前 5 个结果 |
| 结果列表 | 取「整个匹配值」或「每个匹配的组」时有值，取「第一个匹配的组」时为空 |
| 原始匹配对象 | 可在 Python 表达式里进一步处理 |

## 没有匹配

返回错误 `正则匹配失败，没有匹配任何值`，按「失败时中止」决定是否中断。

## 调试

编辑器里该模块带**正则测试器**：填样例文本和正则，直接看到匹配结果和分组，不用反复运行动作。
