title: 运行 C# 代码
sidebar_position: 21
---

用 Roslyn 编译并执行一段 C# 代码，适合做复杂计算、调用 .NET 库。

**前置条件：系统里必须装有 .NET 7 运行时**（见 [安装](/install)）。缺失时启动阶段会弹提示，该模块不可用。

## 参数

| 参数 | 状态 | 说明 |
| --- | --- | --- |
| 代码 | ✅ | 完整的 C# 方法体，默认模板里返回 `"Hello Quicker"` |
| 引用 DLL | ✅ | 每行一个路径，会追加到编译器的引用列表并重新解析 |
| 运行模式 | ❌ 隐藏 | 只有 Roslyn 一种模式，参数不再生效 |
| 参数值 | ❌ 隐藏 | 无法通过参数把值传给 `EntryPoint` |
| 等待结果 | ❌ 隐藏 | 恒为「等待」 |
| 缓存 | ❌ 隐藏 | |
| 超时 | ❌ 隐藏 | **当前没有超时**，脚本死循环会一直占着动作 |

结果通过 「返回内容」 输出返回。

## 可用的上下文对象

代码里可以直接访问：

- `ActionId` / `ActionTitle`：当前动作的 ID 与标题
- `_symbols`：动作的变量表
- Python 侧传入的 `ActionContext`（包装后暴露给 C#）

需要把复杂对象带回动作时，目标变量请用 **动态对象** 类型，否则会被转成字符串（见 [变量](/xaction/variable)）。

## 注意

- **没有超时**：写循环一定要有退出条件。
- 单次编译有开销，频繁调用的热路径建议写成「运行 Python 片段」步骤或子程序。
- 引用第三方 DLL 时路径必须是绝对路径，且架构要与应用一致（arm64/x86_64）。

## 平台

macOS 与 Linux 都支持；Linux 包内置了 .NET 与 Roslyn 运行时，macOS 使用系统安装的 .NET 7。
