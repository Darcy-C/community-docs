打开文件、文件夹、网址，或启动一个程序。

## 参数

| 参数 | 说明 |
| --- | --- |
| 路径 | 程序/文件/文件夹/URL |
| 参数 | 传给程序的命令行参数 |
| 设置工作目录 | 留空时工作目录是 `/` |
| 等待退出 | 等待进程结束，并收集退出码与输出 |
| 已运行时激活窗口 | 目前**没有实际效果**（见下） |
| 备用路径 | 主路径不存在时使用 |
| 环境变量 | 每行 `KEY=VALUE` |
| 失败时中止 | 路径不存在时是否直接报错 |

## 行为

- **macOS**：用 `open` 打开。`.app` 结尾才按「应用」处理（会等待、可拿退出码）。
- **Linux**：用 `xdg-open`。
- 非应用类（文件/文件夹/URL）不会填充控制台输出与退出代码，即使勾了「等待退出」。
- 走命令分支时（带参数的程序），退出码非 0 会报错：`返回状态码不等于0`。

## 「已运行时激活窗口」

这个选项现在仍然显示并可勾选，但实现里两条分支最终都只是 `open <path>`，所以**勾了也不会真的去激活已运行的实例**。需要「已有实例则聚焦」的行为，请用 [获取窗口信息/查找窗口](/xaction/window-info) + [窗口操作] 自己实现。

## 平台差异

- macOS 上 `.app` 有特殊处理；Linux 上没有「应用」概念，必须交给 `xdg-open` 或桌面注册的处理程序。
- 「以管理员模式运行」参数已经不存在（不是隐藏）。
