---
title: 运行脚本
sidebar_position: 22
---

调用系统命令、shell 脚本或指定解释器执行脚本文件。

**平台：仅 macOS**（依赖 AppleScript / `/bin/bash`）。Linux 版隐藏该模块。

## 三种类型

| 类型 | 实现 | 说明 |
| --- | --- | --- |
| 终端命令 | 让「终端」执行 | 会打开终端窗口；**不返回标准输出**，即使勾了「等待执行结束」 |
| Bash 脚本 | 用 `/bin/bash` 执行临时脚本 | 可等待并拿到输出 |
| 自定义解释器 | 你指定的解释器 + 参数模板 | 参数通过 `%FILE%` 传入，以 argv 传递（不经过 shell，无注入风险） |

## 参数

| 参数 | 说明 |
| --- | --- |
| 脚本内容 | 要执行的代码 |
| 工作目录 | 留空时是 `/`，不是脚本所在目录 |
| 脚本参数 | 按 shell 规则切分后作为 argv 追加 |
| 等待执行结束 | 关闭时不填任何输出（异步） |
| 控制台输出编码 | 决定怎么解码 stdout/stderr |

输出：`stdout`、「错误输出」、「退出代码」。

:::warning[编码选项]
「控制台输出编码」请明确选 **UTF8**。默认项在当前版本可能直接报错，且 `UTF8（有 BOM）` 实际写出的也是无 BOM 的 UTF-8。
:::

## 注意

- 没有 AHK 支持：未知类型不会报错，而是**什么都不做**（行为上像成功）。
- 「以管理员身份运行」这个参数已经不存在了（不是隐藏），需要提权请自己写 `sudo` 并配置免密。
- 通过「终端命令」执行时看不到输出，需要输出请用 Bash 或自定义解释器。
