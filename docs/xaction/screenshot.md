---
title: 屏幕截图
sidebar_position: 3
---

截取屏幕、窗口或区域，结果放进图片变量。

## 截图方式

| 值 | 说明 |
| --- | --- |
| 手动框选 | 默认方式 |
| 全部屏幕 | 所有屏幕自动拼接成一张 |
| 主屏 | 只截主显示器 |
| 固定区域 | 用「截图区域」指定坐标 |
| 指定窗口 | 按窗口句柄截（「指定窗口」与「指定窗口（含背景）」目前是同一条路径，没有阴影差异） |

## 参数

| 参数 | 说明 |
| --- | --- |
| 截图区域 | 固定区域时使用，格式 **`x,y,右,下`**（不是宽高） |
| 窗口句柄 | 指定窗口时使用，来自 [获取窗口信息](/xaction/window-info) |
| 延迟 | 截图前等待的毫秒数，用来等 UI 动画结束 |
| 复制到剪贴板 | 同时写入剪贴板 |
| 失败时中止 | |

## 输出

| 输出 | 说明 |
| --- | --- |
| 图片 | 图片变量 |
| 截图区域 | 左、上、右、下；**手动框选方式不会填** |
| 是否成功 | |

## 实现细节

- **macOS** 用系统截图能力，因此**必须授权「屏幕录制」**，否则拿到的是空白或失败。
- **Linux** 通过 X11 抓取，多屏是拼出来的。
- 「全部屏幕」会把低 DPI 屏按最高缩放比统一放大，避免拼接后错位。
- 固定区域必须落在**同一块屏幕**内，否则报 `似乎没有找到该区域`。

:::tip

截完图后要识别文字，直接用 [基础OCR](/xaction/ocr)（macOS）或 [屏幕找图](/xaction/find-image)；需要先处理图片（裁剪、缩放）再走后续步骤时，把「图片」输出交给下游即可。

:::
