title: 模拟按键
sidebar_position: 9
---

发送按键组合（含修饰键）到当前前台应用。游戏或某些自绘界面可能不认这类合成按键。

## 参数

| 参数 | 说明 |
| --- | --- |
| 按键 | 录制得到的一组虚拟键码，内部以 JSON 保存 |
| 重复次数 | 连发几次 |
| 间隔 | 两次之间的毫秒数 |
| 按住时长 | 每个键按住的毫秒数；填 `-1` 用默认 50 ms |

## 录制

在步骤详情里点录制，按下组合键即可。录制的是**全局真实按键**：

- 单独按修饰键（`⌘`、`⌥`、`⌃`、`⇧`）也能录进去，发送时会**短暂点按**（默认 50 ms），不会一直按住。
- 录制超过 3 秒没有新按键会超时，并提示重置按键状态。
- 录制时 Esc / 回车只用于关闭对话框，不会被吞掉，所以它们可以正常录制（回车问题在 2027.4.2 修复）。

## 平台

- macOS 与 Linux 都支持。
- **存的虚拟键码是 macOS 的**；Linux 上会自动翻译成 X11 keysym，所以动作可以跨平台用，但手写 vk 数字不可移植。
- 需要**长按**修饰键、按下不松开时，用 [按键操作](/xaction/key-operation)，本模块做不到。

:::warning

合成的按键事件一般不会触发「全局热键」类监听（包括 Quicker 自己的触发键），这是系统层面的限制，不是模块的问题。

:::
