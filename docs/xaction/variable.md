动作里的变量有名字、类型和值。步骤把结果写进变量，后续步骤再用 `{变量名}` 插值或在表达式里引用。

## 类型

| 类型 | 说明 |
| --- | --- |
| 文本 | 最常用，插值时默认转成字符串 |
| 数字（小数 / 整数） | 参与表达式计算 |
| 布尔 | 条件判断 |
| 图片 | 截图/找图的中间结果 |
| 列表 | 有序集合 |
| 词典 | 键值对 |
| 日期时间 | |
| 动态对象 | 保留原始对象，见下 |

## 在表达式里是什么类型

- **列表**进入 C# 表达式时是字符串列表：元素会被逐个转成文本，所以放进去的数字、对象都会变成字符串。
- **词典**如果所有值都是字符串，按「字符串 → 字符串」映射；否则按「字符串 → 对象」映射。
- 日期时间、整数、布尔按类型映射。

## 动态对象（`Any`）

只有 **动态对象** 会原样保留 C# 返回的对象。其他类型都会经过一次转换，转换不了的会被转成字符串或丢弃。所以：

> 从 C# 脚本/表达式拿到非基础类型（自定义类、`Task`、句柄等），请把目标变量设为**动态对象**，否则拿到的多半是一个字符串。

## 状态变量会持久化

标记为「状态」的变量在每次赋值后写入动作的状态文件，下次运行动作时还在。用它可以做「计数」「上次运行时间」这类跨次记忆。状态文件位置见 [维护工具](/settings/maintenance)。

## 用法示例

```text
{变量名}               插值，任意参数里都能用
{=变量名} / 表达式       计算、条件、脚本里引用
```

## 注意

- 变量名区分大小写。
- 插值只做文本替换；需要运算请用 `{= ... }` 表达式。
- 列表/词典在插值里会变成类似 `a,b,c` / `{k:v}` 的字符串，需要结构化数据时不要靠插值传递。
