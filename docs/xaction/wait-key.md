---
title: 等待按键
sidebar_position: 16
---

阻塞动作，直到用户按下指定的键（或鼠标键）。做「按任意键继续」「快捷键确认」这类交互时用。

## 参数

| 参数 | 说明 |
| --- | --- |
| 等待的按键 | 逗号分隔的按键列表，例如 `11,54`；**留空表示任意键** |
| 修饰键 | 逗号分隔的虚拟键码，必须同时按住 |
| 操作 | 等待按下 / 等待抬起 / 等待所有键抬起 |
| 最长等待 | 超时时间（秒），超时后步骤失败 |
| 过滤事件 | 只处理指定来源的按键事件 |
| 鼠标穿透 | 等待期间是否允许点击穿透到下层窗口 |

## 鼠标键也能等

「等待的按键」支持鼠标左键和右键 LButton,RButton，命中后「键名」返回对应的鼠标键。

## 输出

| 输出 | 说明 |
| --- | --- |
| 「键值」 / 「键名」 | 命中的键（虚拟键码 / 名字） |
| 「按下保持时间」 | 从按下到松开的时长（仅键盘） |

超时未等到：`没有等待到所需的按键`。

## 平台差异

- **macOS**：键码是系统虚拟键码。
- **Linux (X11)**：同样是数字，但含义与 macOS 不同；跨平台时不要照抄数字，用动作编辑器里的按键选择器最稳。
- 系统级媒体键（音量、亮度）不一定产生标准键码，等不到属正常现象。
