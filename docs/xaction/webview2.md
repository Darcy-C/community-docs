打开一个内嵌浏览器窗口，或用脚本操作已有的窗口。模块名沿用 Windows 版，**实际实现是 macOS 的 WKWebView**，和 Windows 的 WebView2/Edge 无关。

**平台：仅 macOS**，Linux 版隐藏该模块。

## 操作

| 操作 | 说明 |
| --- | --- |
| 打开网址 | 显示窗口并加载 |
| 打开并等待关闭 | 与上一个基本相同（当前实现没有额外差异） |
| 执行脚本 | 在页面里跑 JS，结果字符串化后从 「脚本运行结果」 返回 |
| 查询窗口状态 | 是否还开着 |
| 关闭 / 重新加载 / 停止加载 | 常规控制 |
| 检查是否安装 | **恒为 true**：组件是系统自带的，不需要安装 |

## 参数

支持设置 User Agent、窗口标题、是否置顶、是否占用焦点、失去焦点后是否隐藏、是否按 Esc 关闭、是否显示工具栏，以及「窗口标识」（见下）。

输出：窗口句柄、WebView 对象、脚本运行结果。

## 「窗口标识」的坑

文档里写「`=` 表示当前动作 ID」，实际代码取的是**动作作者的 UID**。也就是说：

- 用 `=` 时，同一个作者的不同动作打开的窗口会**互相影响**（关一个可能把另一个也关了）。
- 想精确定位窗口，请显式填一个唯一的字符串。

## 和「浏览器控制」的区别

| | WebView2 窗口 | 浏览器控制 |
| --- | --- | --- |
| 打开的是 | 应用内的独立窗口 | 你真实的 Chrome/Safari |
| 能操作 | 只有这个窗口 | 标签页、元素、脚本 |
| 用途 | 显示网页、做轻量 UI | 自动化已登录的浏览器 |

:::tip

窗口失去焦点自动隐藏适合做「临时面板」；不占用焦点适合做悬浮提示。

:::
