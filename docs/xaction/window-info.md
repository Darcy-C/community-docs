读取窗口的标题、位置、所属进程等信息，也可以按条件查找窗口。后续的「窗口操作」「激活窗口」都靠它拿到的句柄。

## 选择方式

| 方式 | 说明 |
| --- | --- |
| 前台窗口 | 当前激活的窗口（只有这一项会填程序路径） |
| 手动选择 | 点一下屏幕上的目标窗口 |
| 鼠标指向 | 鼠标所在位置的窗口 |
| 按句柄 | 传入已有的窗口句柄 |
| 顶层窗口列表 | 返回「句柄 → 标题」的字典，只含屏幕上可见的窗口 |
| 查找窗口 | 按标题/进程过滤，见下 |

### 查找窗口的匹配规则

- **窗口名**：勾选「使用正则」时是 `re.match`（**从开头匹配**，不是包含）；不勾时按包含匹配。
- **进程**：纯数字按 PID 精确匹配，否则按**进程名的子串**（不区分大小写）匹配。
- **仅可见窗口**：只有选「是」才生效，默认不筛选。

## 输出

| 输出 | 说明 |
| --- | --- |
| 窗口标题 / 句柄 | 标题与句柄 |
| 「进程ID」 / 「进程名」 / `path` | 进程信息（`path` 只在「前台窗口」下有效） |
| 窗口位置 | 左、上、右、下、宽、高 |
| 「窗口位置（不含尺寸）」 / 「窗口位置（词典值）」 | 不带尺寸的矩形 / 字典形式 |
| 「是否可见」 / 「不透明度」 | 是否可见、透明度 |
| 「所有顶层窗口」 | 所有可见顶层窗口的字典 |

:::warning[找不到窗口不会报错]
「查找窗口」「按句柄」找不到时，输出为空但 `isSuccess` 仍为 `true`。需要判断是否命中，请自己检查 「句柄」 是否为空。
:::

「窗口句柄」 传入非数字会直接抛运行时错误，值请来自上游步骤的输出。

## 平台

- macOS 与 Linux 都支持，取的是系统窗口列表。
- Linux 上「鼠标指向」的层叠顺序有已知偏差，可能取到被遮挡的窗口；对准确性有要求时改用「查找窗口」。
- 需要**窗口里的控件**（按钮、输入框）而不是窗口本身，用「控制界面元素」模块（仅 macOS）。
